# 命名规范

## 任务卡
- 目录：`20_tasks/TASK-XXX/`
- 文件：`task-card.md`
- XXX 从 001 开始递增

## 架构文档
- `10_architecture/project-brief.md`

## 审查报告
- `40_review/review-YYYYMMDD-HHMM.md`
- 例：`review-20260329-1425.md`

## 需求文件
- `00_input/requirement.md`

## 记忆文件
- 日记：`memory/agent-X/daily/YYYY-MM-DD.md`
- 长期：`memory/agent-X/MEMORY.md`
